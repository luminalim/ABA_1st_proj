# 성수동 카페 창업 수요 분석 (ABA 1차 프로젝트)

서울시 상권분석서비스(2021~2025) 기반으로 성수동 커피-음료 시장의 현황과 2031년까지의 매출 시나리오를 분석한 프로젝트입니다.

## 구성
| 경로 | 내용 |
|---|---|
| `index.html` | 인터랙티브 대시보드 (GitHub Pages에서 바로 열림) |
| `01_결과물/` | 통합 보고서(xlsx), 발표 자료(ppt.pdf), 대시보드 HTML |
| `02_분석스크립트/` | 엑셀 생성, 대시보드 생성 스크립트 |
| `03_중간데이터/` | 집계 중간 파일(pkl) |
| `성수_카페_통합패널.csv` | 대시보드 입력 데이터 (2021 Q1~2026 Q1) |
| `seongsu_dashboard.py` | Streamlit 대시보드 |

## 데이터 출처
서울열린데이터광장 상권분석서비스 (추정매출, 점포, 유동인구, 상주인구) / 한국부동산원 임대동향.
원본 파일은 저장소에 포함하지 않았습니다. 서울열린데이터광장에서 직접 내려받아 사용하세요.

## 주요 한계
- 매출은 카드 결제 기준 추정치입니다.
- 점포 수는 상권분석 기준이며, 인허가 기준(영업중 카페 227곳)과 정의가 다릅니다.
- 2031년 시나리오는 적합 모델이 아닌 가정 기반 구조 시나리오입니다.
- 2026년 1분기 이후 매출·점포 자료는 반영되지 않았습니다.

## 실행 방법 (Streamlit)
```
pip install -r requirements.txt
streamlit run seongsu_dashboard.py
```
CSV 파일과 같은 폴더에 두고 실행합니다.
