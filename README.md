# 성수동 카페 창업 수요 분석 (ABA 1차 프로젝트)

## 바로 보기
- 인터랙티브 대시보드: https://snazzy-lebkuchen-f528f3.netlify.app/
- 최종 보고서: `성수동_카페_최종보고서.docx`
- 발표 자료: `ppt.pdf`
- 통합 분석 엑셀: `성수동_카페_통합보고서.xlsx`

## 분석 개요
서울시 상권분석서비스(2021~2025) 기반으로 성수동 커피-음료 시장의 현황과 2031년까지의 매출 시나리오를 분석했습니다.

- 2025년 연 매출 611억 원 (전년 대비 +2.0%)
- 2025년 순감 점포 -16곳 (폐업 101 > 개업 85)
- 2031년 매출 전망: 기준 약 748억 원, 하방 약 576억 원 (가정 기반 시나리오)

## 파일 구성
| 파일 | 내용 |
|---|---|
| `index.html` | 인터랙티브 대시보드 (GitHub Pages용) |
| `성수동_카페_인터랙티브_대시보드.html` | 인터랙티브 대시보드 원본 |
| `성수동_카페_최종보고서.docx` | 최종 보고서 (Word) |
| `성수동_카페_통합보고서.xlsx` | 분석 엑셀 (집계, 백테스트, 시나리오, 기준 정합) |
| `ppt.pdf` | 발표 자료 (6장, 그래프 포함) |
| `seongsu_dashboard.py` | Streamlit 대시보드 코드 |
| `성수_카페_통합패널.csv` | 대시보드 입력 데이터 (2021 Q1~2026 Q1) |
| `requirements.txt` | 실행 패키지 목록 |

## 데이터 출처
- 서울열린데이터광장 상권분석서비스 (추정매출, 점포, 유동인구, 상주인구)
- 한국부동산원 임대동향 (소규모 상가 임대료)

원본 파일은 저장소에 포함하지 않았습니다. 서울열린데이터광장에서 직접 내려받아 사용하세요.

## 주요 한계
- 매출은 카드 결제 기준 추정치입니다.
- 점포 수는 상권분석 기준이며, 인허가 기준(영업중 카페 227곳)과 정의가 다릅니다.
- 2031년 시나리오는 적합 모델이 아닌 가정 기반 구조 시나리오입니다.
- 2026년 1분기 이후 매출·점포 자료는 반영되지 않았습니다.

## Streamlit 대시보드 직접 실행
배포된 주소를 보는 경우 설치는 필요 없습니다. 직접 실행하려면 다음을 따르세요.

```
pip install -r requirements.txt
streamlit run seongsu_dashboard.py
```
CSV 파일과 같은 폴더에 두고 실행합니다.
